# GitHub and push

The canonical remote is `https://github.com/Aprabin98/omarchy-setup.git`.

This repository was consolidated from the earlier `omarchy-dotfiles` repository. That repository's first commit is retained as the parent of the consolidated setup commit, so its full history lives on in `omarchy-setup`.

The previous `vice-city-radial` project source and history are preserved inside `projects/vice-city-radial/`. The standalone `vice-city-radial` GitHub repository is retired; do not recreate it as a separate project. Do not delete the YouTube Music upstream repository; it belongs to its upstream author.

To push after reviewing a commit:

```bash
git push origin main
```
